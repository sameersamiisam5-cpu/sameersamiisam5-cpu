### [FrameForge](https://sameersamiisam5-cpu.github.io/frameforge/)
**High-Performance In-Browser HD/4K Video Frame Extractor** · [Repository](https://github.com/sameersamiisam5-cpu/frameforge)

- *Stack:* JavaScript (ES6+), Canvas 2D API, JSZip, FileSaver.js, PyWebView.
